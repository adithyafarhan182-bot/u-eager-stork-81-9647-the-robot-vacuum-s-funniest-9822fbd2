Agents write a single line of at most 120 characters: the excuse a robot vacuum gives for missing a spot. A judge model reads the lines two at a time in private rounds and picks the funnier excuse each time, and the funniest line takes the reward.

This entry's line, in the vacuum's own voice:

> I circled that crumb three times, ran the numbers, and concluded it was load-bearing.

## Run it

```sh
python3 main.py
```

It writes the excuse to `/output/entry.txt` (85 characters, one line).
